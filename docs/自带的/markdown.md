# 一级标题示例

段落之间通过空行分隔。

第二段内容。_斜体_、**粗体** 和 `等宽字体`。无序列表示例如下：

- 第一项
- 第二项
- 第三项

请注意 --- 不考虑前面的星号 --- 实际文本内容是从第 4 列开始的。

> 引用块可以
> 像这样书写。
>
> 如果你愿意，
> 它也可以跨越多个段落。

使用 3 个连字符表示破折号。使用 2 个连字符表示范围（例如“第 12--14 章”）。三个点 ... 会被转换为省略号。支持 Unicode。☺

## 二级标题示例

下面是一个有序列表示例：

1. 第一项
2. 第二项
3. 第三项

再次注意实际文本从左侧第 4 列（4 个字符）开始。下面是一段代码示例：

    # 再重复一遍 ...
    for i in 1 .. 10 { do-something(i) }

你已经猜到了：这里使用了 4 个空格缩进。顺便说一下，除了缩进代码块，你也可以使用围栏代码块：

```
define foobar() {
    print "欢迎来到示例地带！";
}
```

（这样复制粘贴会更方便）。你还可以为围栏代码块指定语言，让 Pandoc 进行语法高亮：

```python
import time
# 快点，数到十！
for i in range(10):
    # （但也别 *太* 快）
    time.sleep(0.5)
    print i
```

### 三级标题示例

下面是一个嵌套列表示例：

1. 先准备以下食材：

    - 胡萝卜
    - 芹菜
    - 扁豆

2. 烧一锅水。

3. 把所有东西倒进锅里，然后按这个流程操作：

        找到木勺
        打开锅盖
        搅拌
        盖上锅盖
        小心地把木勺平衡在锅柄上
        等 10 分钟
        回到第一步（或者煮好后关火）

    不要碰到木勺，否则它会掉下来。

再次注意文本始终对齐到 4 个空格缩进（包括上面第 3 项继续的那一行）。

这里有一个 [网站链接](http://foo.bar)、一个 [本地文档](local-doc.html)，以及一个 [当前文档中的小节标题](#二级标题示例)。这里还有一个脚注 [^1]。

[^1]: 这里是脚注内容。
