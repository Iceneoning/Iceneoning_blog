# 这是一篇草稿文章

这篇文章当前处于草稿状态，尚未发布，因此不会对普通访客可见。内容仍在完善中，后续可能还需要继续编辑与校对。

当文章准备发布时，你可以将 Frontmatter 中的 "draft" 字段改为 "false"：

```markdown
---
title: 草稿示例
published: 2024-01-11T04:40:26.381Z
tags: [Markdown, 博客, 演示]
category: 示例
draft: false
---
