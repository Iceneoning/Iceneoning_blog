## 本轮实施摘要

- 将 `ImageWrapper.astro` 的全源码 glob 收窄为图片扩展名，修复所有路由样式被错误纳入每个页面的问题。
- 显式拆分公共样式、Markdown 样式和路由样式；PhotoSwipe CSS 改为有图片时按需注入。
- Roboto 仅保留实际使用的 Latin 子集。
- 删除首屏同步初始化的 OverlayScrollbars，改用带主题色的原生滚动条。
- 合并滚动事件到动画帧，避免同一帧交错读写布局；TOC 改为先测量、后统一写入。
- 鼠标特效在空闲时停止 `requestAnimationFrame` 循环。

生产构建中，友链页首屏 CSS 从 6 个请求降为 2 个；gzip 估算由 `48,534 B` 降为 `14,922 B`。以上是构建产物对比，不替代部署环境中的 Lighthouse 复测。

## 记录约定

每篇优化记录至少包含以下内容：

1. 问题证据和可复现条件。
2. 根因，而不只记录 Lighthouse 提示。
3. 实施方案、涉及文件和风险。
4. 优化前后数据，优先记录至少 3 次测试的中位数。
5. 桌面端、移动端以及浅色/深色主题的回归结果。

测试环境变化会显著影响结果。复测时需要固定页面 URL、构建版本、设备模拟、网络与 CPU 节流条件，并记录 Lighthouse 版本。
