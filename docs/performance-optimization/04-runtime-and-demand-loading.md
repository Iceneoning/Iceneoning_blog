# 04：保持画面表现的运行时与按需加载优化

实施与复测日期：2026-10-11。

本轮约束：保留布局、主题、字体、背景视频与图片、磨砂模糊、光晕、粒子数量、动画速度、开场动画与页面过渡。没有修改样式文件或媒体资产，没有降低分辨率、动画帧率或画质。

## 定位结果与实施

1. **鼠标特效清空整屏画布。** 每次绘制之前都会清理整个视口，即使只有局部波纹与轨迹。改为清理上一帧实际绘制区域，边界额外覆盖抗锯齿与阴影光晕；绘制算法、粒子、随机数、透明度和时间计算保持不变。
2. **小说馆每帧重复写入相同 CSS 变量。** 保留每帧视差插值和原有星尘绘制频率，只在最终格式化的坐标发生变化时写入。鼠标事件记录最新坐标，下一帧先测量再更新样式；相同尺寸不重建画布。
3. **公共脚本携带所有小说功能。** 阅读、展示与星尘脚本改为按页面 DOM 按需导入。首次导入时初始化，后续由各模块已有的 Swup 生命周期维护。阅读页离开时取消待执行的动画帧、工具栏计时器与全局监听，星尘也在替换内容之前销毁。
4. **阅读页的高频查询与重复更新。** 缓存当前页面的阅读组件与 MediaQueryList，百分比只有变化时才更新文字和 ARIA 属性；仍保持进度条原有精度。
5. **灯箱提前下载完整 PhotoSwipe。** 保留灯箱事件绑定与样式初始化，主模块在打开图片时导入。给异步初始化增加代次检查，防止切换页面期间的旧请求重新创建灯箱。
6. **搜索取回所有结果后只展示 12 条。** 在读取结果片段之前截取前 12 条，丢弃已经过期的请求与错误回调，显示数量与顺序保持原样。
7. **手机预加载了桌面背景。** 为两种原始背景各加匹配现有 CSS 断点的 `media` 条件，手机提前发现自己的图片并避免下载未使用的桌面海报。
8. **归档页隐藏封面仍请求图片。** 对筛选卡片显式设置原生懒加载与异步解码，未显示的封面不请求；筛选展示时正常加载原始图片。

## 本地对照

环境：Windows、已安装的 Microsoft Edge，Playwright 自动化，生产构建与 `astro preview`，`http://127.0.0.1:4321/`。桌面视口为 1440 × 900，没有网络或 CPU 节流。首页、小说馆和第一章各运行 3 次，统计每次稳定空闲 3 秒以及同一鼠标点击与轨迹场景。

原始记录保存在被 Git 忽略的 `.codex-fps-frames/performance/` 中，包括 `baseline/results.json`、`optimized/results.json` 与回归截图。

清理面积是画布工作量，**不等于 FPS 提升比例**。浏览器原本会过滤相同 CSS 值，空闲样式重算在两版中均为零；本轮只声称消除了重复脚本调用。这里没有把本地请求时长当成线上 LCP 或 INP，也没有用构建耗时作性能收益。

## 画面与功能验证

- 鼠标特效使用固定随机种子与相同时间输入，逐帧读取完整 RGBA 像素并比较 SHA-256：DPR 1 / 2，以及默认、最大、最小三组特效设置，每组 180 帧，共 1,080 对帧完全一致。场景包括多个同时爆发的波纹、连续轨迹、相距很远的粒子及画布边缘。
- 1440 × 900 桌面和 390 × 844 手机均完成重复站内切换、小说阅读设置、滚动到 100%、分类归档、灯箱开启/关闭、空屏开启/Escape 退出；无新增页面脚本异常或横向溢出。
- 首页实际请求中没有小说模块；文章进入时没有完整灯箱模块，点击图片后才出现该模块。
- 真实 Pagefind 搜索“游戏”返回 10 条结果；100 命中构造用例只读取并显示 12 条。
- 手机请求中有原始手机背景，没有桌面海报或 MP4。
- 强制重播开场动画正常完成并清理遮罩；减少动态效果偏好下保留静态星尘、不加载 MP4、不播放开场动画。
- `pnpm check`：75 个文件，0 错误、0 警告、0 提示。
- `pnpm build`：成功生成 20 个页面与 16 个可搜索页面。
- `git diff --check`：通过。

## 复测脚本

使用已有 Playwright 与 Edge，不安装依赖或下载浏览器。`PLAYWRIGHT_MODULE` 可指定现有 Playwright 包的绝对路径；默认按项目模块解析。`AUDIT_BROWSER` 默认为 `msedge`，`AUDIT_URL` 默认为本地预览地址。

```powershell
pnpm build
pnpm preview --host 127.0.0.1 --port 4321
# 在另一终端执行；先在修改前记录基线，再修改代码并构建。
$env:PLAYWRIGHT_MODULE = '现有 Playwright 包的绝对路径'
node scripts/performance-audit.mjs baseline
# 修改后：
node scripts/performance-audit.mjs optimized
node scripts/performance-regression.mjs
```

回归脚本依赖 `baseline` 保存的鼠标特效源码。测试截图与临时文件留在项目已有的忽略目录，便于复查，不会发布为博客内容。

## 实际限制

保留的 1080p 动态背景、全屏与卡片磨砂仍有视频解码和 GPU 合成成本；本轮没有降低这些效果。线上首屏、移动设备与较弱 GPU 的实际流畅度还需要在部署后的相同设备、网络条件下测量。本轮结果已覆盖可确认的无效绘制、资源加载与事件生命周期开销。
