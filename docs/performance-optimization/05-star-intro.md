# 05：保持开场动画画面的优化

日期：2026-10-11。对应脚本：`src/scripts/star-intro.ts`。

保留全部星点、颜色、透明度、涟漪与撕裂公式，3.6 秒时间轴、星海纹理上传频率、画布分辨率上限、文字淡入淡出和页面揭幕过渡均保持原样。最终没有修改 GLSL 着色器。

## 改动

- 每个纹理帧有 1,203 次涟漪采样，原先每次采样都重算相同的宽高比、主波半径、回声半径和两段平滑插值。现在每帧只计算一次这些公共量，保留原有乘法顺序与精度。
- 首次上传及尺寸变化时用 `texImage2D` 定义纹理；相同尺寸时使用 `texSubImage2D` 更新已有纹理。上传次数与像素数没有减少，避免重复定义纹理尺寸。[接口文档](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/texSubImage2D)
- 固定的风格、星光强度和水面强度只在初始化时提交；分辨率只在纹理尺寸变化时提交。时间和进度仍逐帧更新。
- WebGL 正常工作时，隐藏回退画布保留默认小尺寸；需要 2D 回退时才扩展到当前画面尺寸。窗口事件未改变实际缓冲区尺寸时，跳过重建静态星海与重复上传。
- 文字透明度值未改变时，跳过重复的 DOM 样式写入。
- 补上原先缺失的 `webglcontextlost` 事件绑定，正常使用已有回退函数；清理时继续移除监听、释放纹理与程序、缩小画布并移除遮罩。

## 验证

`scripts/intro-regression.mjs` 使用修改前保存的脚本作为对照，固定时间点并读取 Canvas2D 与 WebGL 完整像素做 SHA-256 比较。

- 640 × 360、390 × 844、1440 × 900 三种视口，各比较 12 个时间点，包括撕裂起点前后，共 36 对源纹理和最终 GPU 画面均完全一致。
- 三种视口缩放后的画面均一致，无 WebGL 错误。
- WebGL 不可用时，12 个时间点的 2D 回退画面一致。
- 模拟上下文丢失时，回退画布按需恢复到当前尺寸；销毁后所有画布缩回 1 × 1，遮罩被移除。
- 生产页面强制重播正常结束，减少动态效果偏好仍生效。
- `pnpm check`、`pnpm build`、`git diff --check` 通过。

固定尺寸下，初始化与 12 个采样帧合计的调用对照：

| 调用 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 纹理尺寸定义 `texImage2D` | 13 | 1 |
| 更新已有纹理 `texSubImage2D` | 0 | 12 |
| 浮点/分辨率参数提交 | 78 | 30 |

额外做了三轮独立的完整播放对照，交替测试新旧脚本。测试环境为本地 Edge、1440 × 900、真实 `requestAnimationFrame`，单独呈现开场画布，未加载博客背景视频和其他页面组件。

| 指标 | 修改前中位数 | 修改后中位数 |
| --- | ---: | ---: |
| 每帧脚本执行耗时，排除最后的清理帧 | 0.953 ms | 0.904 ms |
| 帧间隔 P95 | 6.3 ms | 6.3 ms |

脚本耗时降低约 5.2%，帧间隔基本不变；本机没有显示出大幅帧率提升。GPU 仍执行原来的完整全屏着色器，实际博客环境还叠加视频解码与合成，不能把这些独立测试数值直接当成线上体验。

原始结果在 Git 忽略目录 `.codex-fps-frames/performance/intro/`：`results.json`、`live-results.json` 与修改前的 `baseline.ts`。

## 画面约束

曾验证过在撕裂开始前跳过撕裂噪声计算的分支。该方案在 GPU 像素对照中出现差异，已撤回，最终保留原着色器。后续更深的 GPU 优化仍需保持分辨率、采样频率与公式，并继续做画面对照。

## 复测

需要已有 Playwright、Edge 和项目 TypeScript，无需安装依赖。先保存修改前基线，再进行优化与比较：

```powershell
$env:PLAYWRIGHT_MODULE = '已有 Playwright 包的绝对路径'
node scripts/intro-regression.mjs --save-baseline
# 修改脚本后，在生产预览运行期间执行：
node scripts/intro-regression.mjs
```

`AUDIT_URL` 默认 `http://127.0.0.1:4321`，`AUDIT_BROWSER` 默认 `msedge`。本地强制重播地址为 `http://127.0.0.1:4321/?intro=1`。
