# 冰霜旅途｜背景与航线系统规范

> 状态：SUPERSEDED / 历史航线背景设计；新目标是 [V0.3 少女与冰晶折射](../../V0.3_晴空冰晶折射/02_背景美少女与冰晶折射美术方案.md)，不可再按航线 HUD 施工。
> 优先级：保护原画 > 空间层次 > 航线叙事 > 装饰动态

## 1. 背景不再只是壁纸

当前背景已有明确的人物与亮部构图。此前 Fog/Blur/Volumetric/Depth Map 试验出现灰、雾蒙蒙、人物被拉扯等问题。新方案不再做整屏滤镜，而是把可识别的**航线**放到背景空白处，配合有限的信标和晶面几何，创造一眼可认的“旅程记录”语言。

视觉核心是**晴朗有阳光**，不是冷灰、雪天、雨天或暗色赛博科技站。

## 2. 图层结构与职责

```text
原始背景图（保真，仅低幅 Pointer Parallax）
  └─ 现有全局背景/主题调节（保持必要可读性，不新增变灰效果）
      └─ 静态旅途航线（SVG；仅装饰，依屏幕空白锚定）
          └─ 关键节点 / 少量冰晶切面（CSS / SVG）
              └─ 可选低密度 Canvas 2D 光尘（在适用页面、可暂停）
                  └─ 站点 UI（文字始终优先；跨层级按现有 Shell 核对）
```

示意不是对现有 DOM 的事实描述；Astar 应审计 `Layout.astro`、`SiteGraphicsLayer.astro` 等现状后落地。**不要为了一个效果重建整棵 Layout**。

## 3. 主航线怎么画

方案为 1 条主要弧线、1～2 条极淡短支线，以及 3～5 个具有节奏的节点；这些是**首页桌面上限**而非每个页面的必配量。

- 主线以 Bezier 曲线穿行于留白：由站点识别附近的起点，经中心内容外缘，到右侧时间区附近的终点。
- 路线视觉上可以“关联”卡片，但**不可横跨文章正文、头像面部、重要插画细节或卡片上方**；实际定位可以拆成被遮挡的短段。
- 静态段建议 1～1.5px 的低 Alpha 蓝白线，某一小段可有不超过约 2px 的高光。
- 线条始末点必须形成视觉因果：一个小“发光起点”+若干弱节点+一处可停留的主信标。
- 不画高密度城市地图路线/完整坐标 HUD；不展示没有业务含义的精确经纬度。

## 4. 信标（Beacon）

信标是全站唯一强识别符号：冷白核心、小晴蓝外光圈、细微缺口圆环，尺寸可从 6～14px 起步。它既是页面“旅程”的起点/终点，也是开场光迹收束之处。

静态时可见但不抢标题；Hover/导航切换时短时间高亮。没有动画时同样完整成立；装饰不是可点击按钮，除非关联实际链接语义。

## 5. 冰晶的边界

“冰”体现为细薄折线、少量半透明切面、亮边，而**不是**铺满全屏的雪花、分形冰裂或磨砂滤镜。

- 只在角落/航线转折/首页焦点附近使用 1～2 个小切面；
- 不叠到角色脸、腿、高亮白衣等背景主体上；
- 能见度低于信标与 UI 标题；
- 移动端可完全隐藏。

## 6. 背景视差

继续利用已有单层 Pointer Parallax，推荐保持现有量级（历史文档约 X ±8px / Y ±5px，以源码实际值为准）；切忌对角色各部位做 Depth Map 拉扯。

规范：

- 只动背景层，不动 Navbar/侧栏/正文，避免视觉跟手导致头晕；
- 需要 `scale` 留边，不能产生露底或黑边；
- `prefers-reduced-motion`、粗指针及小屏自动关闭；
- 页面切换不重新实例化背景；
- 停止交互后，惯性收敛完毕应停止持续绘制。

## 7. 空气光尘（可选 V2）

光尘不等于星空或雪：淡冷白、极慢、小颗粒，以环境漂浮为唯一任务。

- 首页桌面建议 20～40 个为初始试验范围，绝非硬性数量；其他页面更少或关闭。
- 同时可见的高亮粒子应远少于总数；可见密度由截图判断。
- 运行上限取决于性能评估与视觉测试；在阅读页禁用动态光尘。
- Canvas 2D 仅作为低依赖实现候选；不允许粒子每个对应一个 DOM 节点。
- 页面不可见、Reduced Motion、低性能模式应暂停；按需渲染优于常驻 60FPS。

## 8. 不采用的方案

- 全屏 Fog / Volumetric Fog / FBM 烟雾 / 灰白洗屏；
- 将整张背景压暗、去饱和或做长时间 Blur；
- Depth Map Parallax（人物剪影变形）；
- 全屏 Canvas 纹理噪声、长时 Grain、雪花雨、粒子雨、超密 Technical Grid；
- 大面积 Bloom、色散、液态玻璃、屏幕空间折射作为全局背景；
- 鼠标光束追逐人物、强烈鼠标闪光特效抢视觉中心。

已有 `MouseSparkEffect` 是独立的点击反馈，Astar 不得为了航线动效叠加第二套全局鼠标拖尾。

## 9. 浏览器/布局工程合同

首帧背景图就应出现（可能受正常网络加载影响，但不可人为盖黑布）；即使 SVG 或 Canvas 加载失败也显示原网站。装饰层须在交互上透明，不引入水平滚动条，支持 Resize、页面切换后正确位置重算，但不修改主内容 DOM 尺寸。

背景主图建议保持当前 WebP 资产与配置，**不能因本方案自动替换图片**。任何换图、裁切、角色主视觉重绘都需要先出方案供用户确定。

## 10. 验收场景

对比开关装饰层前后截图：人物原色和高光基本一致，画面不变灰；路线能在 1440px 首页被看出，但不穿越正文，移动端只剩简洁标识；Light/Dark/Hue 切换后线与文字均可读；失去动画功能后静态版仍然完整、没有黑屏。
