# 美化方案索引

本目录用于集中记录博客全站后续的纯视觉美化方案。

原则：

- 不重新发明一套与 Fuwari 割裂的 UI；
- 美化优先依靠光影、层次、插画、动效与留白，而不是继续增加信息组件；
- 首页、文章页、小说区、介绍页等页面分别记录，避免所有视觉实验继续堆在某一个功能版本目录中；
- 每次方案都必须经过实际页面截图复核，再决定是否成为正式基线。

当前方案：

1. [01_小说馆Hero光影过渡方案.md](./01_小说馆Hero光影过渡方案.md)
   - 记录 Visual V3.2 系列从静态 CSS 光影到可见光场的探索过程。
   - 保留为视觉迭代记录，不再作为当前实现结构的最终工程基线。

2. [02_小说馆Hero图形化实现方案.md](./02_小说馆Hero图形化实现方案.md)
   - Visual V3.3 当前工程基线。
   - 使用 CSS 环境光场 + SVG 轨道 + Canvas 粒子 + 轻量 2.5D 视差。
   - 图形系统保持通用，不与某一部小说主题硬绑定。

3. [03_全站图形学视觉层美化方案.md](./03_全站图形学视觉层美化方案.md)
   - Lightweight Visual Layer V1 为当前全站视觉基线；全屏 Fog/WebGL Shader 已移除。
   - 布局已恢复到“崭新出炉 / 精彩回顾”改版边界；后续 Typography / Spacing 实验已回退。
   - 保留 Background Parallax、Mouse Edge Light、Technical Grid 与常驻 Swup 外图形层。
   - 当前不再使用全屏 WebGL 背景 Shader；背景插画保持原始色彩与高光。

4. [04_视觉系统重构与DepthMapParallax方案.md](./04_视觉系统重构与DepthMapParallax方案.md)
   - 记录 Fog / Depth Map Parallax 两条背景特效路线的实验与回退结论。
   - 当前恢复单层 Pointer Parallax 与原版卡片透明度。
   - 后续改为局部 UI、微交互、Typography / Spacing 小步精修。
