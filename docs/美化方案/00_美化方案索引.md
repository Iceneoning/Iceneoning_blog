# 博客视觉设计索引

> 当前方向：星空视频背景 + 高透明度、零背景模糊的简洁统一 UI。
> 更新时间：2026-10-11
> 状态：设计原则已确定；Shader 与开场动画暂未进入正式博客。

## 当前设计约束

- **视觉主角**：中央少女与深紫星空 MP4；动画本身负责主要美术表现。
- **组件职责**：负责内容组织和阅读，不叠加独立的冰晶、蕨叶、假折射光场。
- **统一材质**：深紫黑色低不透明度表面、细描边、统一圆角与轻阴影；**不使用 `backdrop-filter` 模糊背景**。
- **布局**：沿用 Navbar、左右侧栏和中间的 Hero + 文章列表；不人为增加大片空白，也不强行缩窄 Hero 来躲避人物。
- **阅读**：文章正文按可读性做局部文字保护，但不恢复大面积毛玻璃。
- **Shader / 开场动画**：未来先做可见差异明确的独立预览，通过用户确认后才接入正式页面。开场必须有独立的视觉叙事，不把背景增强误当开场动画。
- **小说区**：保留功能、作品展示和独立阅读布局；将来只做协调新背景的美术精简，不在清理阶段拆除小说系统。

## PC V1.2 · 松弛三栏（已实施，待视觉验收）

- **适用范围**：宽度不少于 1280px 的三栏桌面布局；小屏布局与手机端图片背景不做调整。
- **材质合同**：Navbar、作者卡、日期面板、Hero、文章列表共用 `rgba(13,16,35,.30)`，无背景模糊；1px 淡紫灰边框，圆角约 13px，极轻微阴影。按钮背景为 `rgba(13,16,35,.38)`，悬停才稍微提亮。
- **整体比例**：宽屏内容最大宽度约 1280px（此前约 1408px），左/右栏约 240px / 200px，中间栏保留弹性阅读宽度，栏间距约 18px；顶部导航降低到约 69px，保留屏幕两侧的背景空间。
- **左侧栏减法**：只保留作者资料卡和社交入口，移除左侧的「分类」「标签」组件及其空白容器；文章分类与标签数据、目录页筛选仍保留。
- **中间栏**：Hero 保持中间栏全宽、自然高度，改为不带跳转按钮的博客序言：先介绍作者写代码、做游戏和故事的兴趣，再以一段克制的星河感想收束。原「阅读最新文章」「技术与游戏」「生活随笔」「故事与小说」快捷链接已移除；全站导航和文章列表仍保留。文章列表以约 18px 正常间距衔接，不留额外空白。
- **阅读与内容**：文章标题、摘要、侧栏小字提高对比度并加轻微文字阴影；**仅长文阅读容器**使用约 52% 深色底，以保证较长段落的阅读安全。
- **职责分离**：PC 的视觉变化集中在 `src/styles/winter-journal.css` 最末的 `@media (min-width: 1280px)` 合同中；整体收窄只约束三栏博客及其导航，不影响独立小说阅读布局。视频播放、视差、Swup、文章封面、小说行为不变；Shader 与开场动画继续待议。

## 代码与素材边界

- 当前正式动态背景：`public/background/star-sea-loop-1080p.mp4`。
- 视频静态回退：`public/background/star-sea-poster.webp`。
- **手机端正式背景**：`public/background/mobile-background.jpg`（原 `DM_20261010133318_001.jpg`），在宽度不超过 900px 时作为页面背景使用，**禁止作为冗余文件清理**。
- **其他需保存的原图**：`public/background/intro.webp`、`site-bg.webp`，分别供站点示例或留念等用途；即使未被页面引用，也不视为冗余。
- 鼠标视差由 `src/scripts/background-parallax.ts` 统一作用于当前 MP4 与静态回退，旧鼠标卡片边缘光仍停用。
- 4K 原片在本地 `source-assets/background/`，不可作为冗余素材删除。
- 旧版设计、实验样片、停用效果源码集中在项目根目录 `_待删除_旧版视觉方案/`，该目录已被 Git 忽略；由用户决定最终删除。
- `src/styles/journey.css`、`winter-art.css`、`winter-crystal.css` 等仍有运行中的排版与兼容规则，不能在未完成逐项迁移前整份删除。
- 文章、小说、主题初始化、Swup 导航、侧栏及功能组件保持原有数据与行为。
