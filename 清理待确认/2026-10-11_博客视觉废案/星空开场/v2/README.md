## 技术分层

1. **背景素材**：保留 `public/background/star-sea-loop-1080p.mp4`，后台初始化播放，不等待视频加载；视频不就绪时保留原 `star-sea-poster.webp` 海报兜底。移动设备使用 `mobile-background.jpg` 静态背景。
2. **JavaScript + Canvas2D**：固定随机种子的分层星空、缓慢漂移、细线星座、流星星尘或淡环。先绘制深紫渐变，最后通过 Canvas 层透明度缓慢揭晓底层背景。
3. **WebGL1 Fragment Shader**：星座线和高光、流星光轨、星环涟漪及闪烁亮点。仅高光透明叠加，不负责整体幕布与黑场。
4. **DOM 文字**：沿用 V1 居中位置（`top:42%; left:50%`），保留「让星河，轻轻泛起涟漪。」文案，不挪到侧边。
5. **收尾**：开场 57%–97% 逐渐淡出星幕，Shader 70%–97% 淡出，文字 70%–93% 淡出；完成后移除动画图层显示「你好，旅人。」静态终帧。不绑定真实博客加载生命周期。

## 性能与失败语义

- Canvas 星点为固定 170 个，无图像请求或第三方依赖；设备像素比限制为桌面 1.25、移动 1，并将 Canvas 总像素限制在约 230 万以内。
- 页面不可见时暂停 rAF 计时；恢复时不快进。视频播放遵循屏幕宽度、指针类型、减少动态效果偏好及 Save-Data。
- WebGL 不支持、编译失败或上下文丢失时继续执行 Canvas2D 动画；Canvas2D 不可用则直接完成。
- 重播 / 跳过 / `prefers-reduced-motion` 可用；不阻塞背景视频或真实页面。
- 最终设计验收后才决定正式接入点。**不得修改生产中的 `Layout.astro`、Swup、页面路由、背景脚本及素材。**

## 验收重点

- 开场不出现黑场/白闪，视频与海报应当在下层持续可用；
- 居中标题保持 V1 位置，字体大小/层次自然；观察是否有锯齿、明暗突变；
- 三种 Shader 的波纹/光轨应当与 JS 星尘有明显联动，但不过度抢占原本的星空视频；
- 快速点击重播、跳过、切后台恢复、小视口与低动态效果均可回退。
