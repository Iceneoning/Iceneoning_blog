## 核心设计：JS 画星空 → WebGL 处理纹理 → 溶解揭晓正式背景

- JS Canvas2D 绘制完整独立星空（235 个活动星点、28 个短暂星芒、静态疏星与浅淡紫星云），视觉配色选取博客原画中的深靛紫 / 冷白 / 少量浅紫金。
- 源 Canvas 不直接显示，而是上传为 **WebGL1 `sampler2D` 纹理**。Fragment Shader 采样真实的星空纹理进行波纹折射、光带聚集和边缘着色；Shader 处理整张画面，不是仅在图上叠三条线。
- 最后约 1.4 秒，GLSL 在中心向外计算噪声扰动的 SDF 揭晓遮罩，逐像素降低星空的 alpha。**遮罩透明处显示的是底下已经存在的 MP4/静态海报。** 结束后 HTML 仿首页内容才渐显。
- 三种方案只改变 Shader 的前半段视觉语汇，均使用同一幕揭晓退场，方便横向比较。
- 高亮边界与衰减使用 `smoothstep`、程序化 value noise、径向距离、正弦波和纹理 UV 偏移；不是 CSS opacity 整屏淡出。

## 交互与失败回退

- 按钮：重播、暂停/继续、跳过、关闭/启用**艺术光效**。
- 滑块：光学效果强度 0–200%。调整到 0 时依然保留 GLSL 溶解转场；禁用的仅是折射和发光效果，方便对比。
- WebGL 不可用/编译错误/上下文丢失：保留 JS 星空，使用均匀透明度衔接作为明确的降级路径；在界面写出 WebGL 不可用。
- 系统设置减少动态效果时：跳过动画，显示静态终帧；浏览器后台时：暂停 rAF，恢复不快进；移动窄屏继续使用静态移动壁纸作为最后背景。
- 渲染源画布最多约 125 万像素，纹理上传约每两帧一次，Shader 渲染与页面请求互不阻塞。
- 视频仅在桌面细指针、无减少动态效果、无 Save-Data 时才获取；无法播放时显示本地 `star-sea-poster.webp`。

## 是否和博客“搭配”？

此处“搭配”指的是**统一色彩和转场叙事，而不是直接拿博客背景当开场星空**。真正的星空演出由 JS 独立产生，最终才揭晓原画中的少女。Shader 特效需要有视觉存在感，但不会把背景视频二次模糊或增加永久光场。
