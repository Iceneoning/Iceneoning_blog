## 主要技术

- 背景来自 JS **Canvas2D**，不复用博客视频：固定深靛紫渐变、局部浅紫星云、**1450 个静态疏星、360 远景微星、135 中景呼吸星、24 近景四芒星、140 星尘点**。不同层速度、明暗和尺度各异，并保留中央标题安全区。
- JS 每次绘制把场景上传为 WebGL1 的 `sampler2D` 源纹理。Texture 仍每两帧更新一次，画布面积最多约 125 万像素。
- GLSL 不使用水波式 UV 折射：以两道不同进度的**径向星纹脉冲**为驱动，角向断裂细丝 + 稀疏星点 + 四芒星；JS 与 Shader 使用同一半径推进公式，波经过星点才临时增亮。
- 星纹形状由 Value Noise、极角周期扰动、网格哈希等组合形成，避免整圈均匀白线。Shader 仅增强局部辉光与星闪，不重新生成整屏雾。
- 以 V4.1 已通过实机验证的「三频噪声、逐像素星幕撕裂」作为最终揭晓，**不**改成整页 CSS opacity 淡出。
- 默认强度 105%，支持重播、暂停、跳过、星纹开关、0–200% 光效强度；弱性能平台 / WebGL 丢失时按原方案回退纯 JS 星空。
- `prefers-reduced-motion` 时直接跳过动画；后台暂停 rAF，恢复时不快进。原视频加载规则和备用海报不变。
