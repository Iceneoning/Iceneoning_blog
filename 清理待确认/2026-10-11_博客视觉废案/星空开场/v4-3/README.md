## 本轮美术目标

1. **星群代替亮环**：减少连续光弧的强度和宽度；通过分散的 GLSL 星芒与四层 JS 星空中的星点逐次响应传递共鸣，保留清晰可辨的传播方向，但避免发光水纹的观感。
2. **星空更耐看**：远景微星 / 中景呼吸星 / 近景四芒星 / 星河星尘，增加少量独立偏移的星光节点，局部浅紫冷蓝星云与星座响应；中心标题依然保持克制。
3. **镜头节奏**：前段静谧苏醒，中段两次错峰星纹脉冲，后段沿用已经验证过的三频噪声裂隙揭晓；文案在少女显现前淡出，不移动位置。
4. **横向对照**：保留旧版演示、重播、暂停、跳过、星纹开关与强度调节，便于用户逐项比较。

## 技术路径

`Canvas2D` 绘制完整独立星空 → WebGL1 `sampler2D` 纹理（隔帧上传）→ GLSL 离散星点、微光波前 → GLSL 逐像素空间撕裂 → 底层原视频或海报及首页内容。

保留降级路径：WebGL 不可用时使用纯 Canvas 星空与均匀透明度退场；系统 `prefers-reduced-motion` 时不播放，页面不可见时暂停。视觉细节改变不意味着可以修改正式 Astro、Swup、视频背景脚本。
