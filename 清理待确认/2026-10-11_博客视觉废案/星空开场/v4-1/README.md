## 截图问题与修改对应

1. **大片、重复的螺旋光环**：原 `gauss(sin(spiral*N), .13)` 会生成大量明亮等值线。新版本改为上、下及边缘共三条细星丝，并让高亮沿曲线流动；文字中心区域额外减少亮度，保留开场白原来的 `top:42%;left:50%`。
2. **中部横向断层**：原 `spiral=d-(.19+.13*atan(q.y,q.x)+...)` 直接将不连续的 `atan` 输出加入曲线，在极角跳变处必然断开；V4.1 的星丝改用屏幕 UV 的连续曲线。揭晓遮罩中的角度扰动仅通过周期整数频率的 `sin(n*atan(...))` 使用，保证接缝两侧值相同。
3. **撕裂揭晓不够细腻**：保留从中心逐像素向外揭晓博客视频的方案，叠加三频 Value Noise 和微小的周期角度波形、细亮边缘、宽柔边缘及少量星光碎屑；不是 CSS 全局透明淡出。
4. **光效视觉权重**：V4.1 默认强度调为 85%，滑块依旧支持 0%–200%。节奏沿用 V4 的约 3.6 秒，避免一轮精修同时改变太多变量。
5. **撕裂边界细节**：实测在约 74% 进度发现大片块状碎屑，因此把碎屑噪声改成更细的 205-scale 分布，并限制在较窄的边界带内，降低边缘光晕。
6. **文案退场节奏**：文字位置不变，但从约 60% 进度开始淡出、约 80% 进度完全退去，避免少女显现后文字仍挡住面部。

## 架构和保护范围

```text
JS Canvas2D 绘制独立星空
      ↓ 上传为 WebGL 纹理
Fragment Shader：稀疏流光 + UV 微扰 + 三频噪声边缘
      ↓ 逐像素透明揭晓
底部原有星空少女 MP4 / 海报 → 「你好，旅人。」静态预览
```

本次只改变镜头内的美术效果及精修控制，未改变独立 Demo 的 Canvas 上传频率、视频加载规则、降级路径、暂停/重播/跳过以及响应减少动态效果的逻辑。
