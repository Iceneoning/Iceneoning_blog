## 为什么制作本版

用户反馈 V4.3 的星纹沿线响应星点偏少，JS 星空精致度不足。本版**提高响应密度但不过度提高整体亮度**，并保留被认可的空间撕裂转场和居中标题。

## 改动与约束

- JS 星空深度层：farStars **360 → 560**，midStars **135 → 220**，nearStars **24 → 42**，dust **140 → 260**，accents **58 → 110**。静态微星 **1450 → 1950**，静态部分仅在画布缩放时重建。
- JS 的中景星点不再全部均匀分布：约 126 颗聚集在四块偏左上、右上、左下和右中边缘的星团区域，其他仍离散分布。局部微流星只出现在视野边缘，避开文案。
- Starfield 的主波和次波引入短时亮度余迹（decaying wake）；命中后的星点先亮、短暂形成四芒星，再快速衰减，不使用大量连续水波线。
- WebGL Shader 中 star grid **45×27 → 58×34**，出星阈值 **0.70 → 0.60**，并按 hash 实现不同亮度。每个格子只在波前经过时响应，不会同时全亮。
- JS 与 GLSL 的主/副波仍共用推进曲线，标题安全区继续压低高亮；Shader 最后仍通过三频噪声逐像素撕开独立星空，揭晓原 MP4。
- 最大 Canvas 像素仍限制在约 **125 万**，WebGL 源纹理每两帧上传；视频加载、reduced-motion、后台暂停和 WebGL 回退逻辑保留。
- 重播、暂停、跳过、星纹开关、强度滑块均保留。默认强度微调为 **93%**；需要通过视觉判断其饱满度。

- `node --check` 通过，Edge 浏览器实测 WebGL Shader 正常编译、原视频 readyState=4。
- 已捕获开场前段、约 50% 星纹传播、约 74% 星幕撕裂、100% 结束画面：星纹响应星点数量明显增多，裂隙中心成功揭示少女背景，文案未持续遮挡面部。
- CDP 交互测试通过：暂停期间动画进度冻结；恢复后进度继续；星纹开关状态切换、跳过、重播均正确；未捕获浏览器 JavaScript runtime exception。
- 性能约束仍保留：Canvas 渲染最大约 125 万像素、纹理隔帧上传；粒子总数增加带来的实际帧耗尚未跨设备量测，不宣称已经达到生产环境性能指标。
- 当前仍是单机 Edge 原型验收，尚未在实际正式博客、移动端、多浏览器全量回归。

1. 约进度 30–65% 的星点响应是不是比 V4.3 明显增多，且不是“满屏乱闪”。

3. 50–100% 的回声与撕裂进场仍连贯，底层少女背景无黑屏、白闪或横向断层。
4. 用 Chrome/Edge 检查 Shader 编译，实测暂停/跳过/重播、减弱动态效果及不同视口。
